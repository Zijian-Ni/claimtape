## EN — English

### Headline
**"Did the AI actually prove that?"**

### Subheadline
Paste any AI answer. Get a claim-by-claim trust report in seconds.  
No API key. No signup. Runs entirely in your browser.

### One-liner
ClaimTape breaks AI answers into atomic claims and badges each one: ✅ Supported · ⚠️ Unsupported · ❌ Contradicted · 🔍 Needs Human.

### Feature bullets
- 📋 **Claim-by-claim breakdown** — every sentence gets a trust badge
- 🚩 **Risk flag detection** — catches "100%", "already deployed", "no bugs" without evidence
- 📊 **Trust Score 0–100** — instant at-a-glance verdict
- 📎 **Evidence upload** — paste logs, JSONL traces, or any text as proof
- 🔒 **100% local** — nothing leaves your browser, ever
- 🌐 **CN/EN bilingual** — toggle in one click
- 📋 **Shareable report** — copy Markdown or export JSON
- ⚡ **Works offline** — download once, use anywhere

### Who it's for
| Audience | Use case |
|----------|---------|
| 🎓 Students | "Did ChatGPT actually support that essay claim?" |
| 📊 Product Managers | "Does this AI spec match the sprint logs?" |
| 💻 Developers | "Did the AI code review really find all the bugs?" |
| 👨‍👩‍👧 Parents | "Which parts of my kid's AI homework are made up?" |
| 📝 Researchers | "Which sentences in this AI summary need citations?" |

### How it works (4 steps)
1. Paste any AI-generated answer
2. Optionally paste or upload trace/log evidence
3. Get a claim-by-claim breakdown with trust badges
4. Copy a shareable Markdown report

### Privacy statement
🔒 ClaimTape runs entirely in your browser. Your text is never sent to any server. No account, no API key, no cookies, no tracking.
